# Customer-owned MCP gateway reference

This local reference composes a customer-signed protection activation with the
existing EMILIA MCP receipt boundary. It makes no network request and receives
no provider credential.

The reference shows that selected consequential tools and unknown mutations
challenge before the handler, while an explicitly configured read-only tool
passes. It does not prove installation, complete mediation, or external effect.

```sh
node --test examples/customer-owned-mcp-gateway/run.test.mjs
node examples/customer-owned-mcp-gateway/run.mjs
```
