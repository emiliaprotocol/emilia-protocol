# Claim Assurance offline reference

This directory contains a deterministic, entirely synthetic Claim Case, pinned
profile, pinned verifier implementation, and content-addressed Assurance Record.

Run the complete offline replay:

```bash
node examples/claim-assurance-reference/generate.mjs --check
```

The replay hashes the verifier source, recomputes the profile and artifact
digests, evaluates the Claim Case, checks the record's self-integrity, and
compares the generated bytes with the committed fixtures.

`VERIFIED` means only that the fictional artifacts satisfied this exact pinned
profile at the fixed evaluation time. The record always carries
`authorizes_action: false`. Its `action_digest` correlates evidence with one
synthetic action; it does not grant permission to perform that action.

`inspectAssuranceRecordIntegrity` checks the record's closed shape and digests.
It deliberately reports `reperformed: false`. Re-performance requires the raw
Claim Case, the independently pinned profile, and the independently pinned
verifier implementation.
