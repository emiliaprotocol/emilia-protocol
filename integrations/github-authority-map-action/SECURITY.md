# Security policy

Please report a vulnerability in EMILIA Authority Map privately to
team@emiliaprotocol.ai. Include the smallest reproducible workflow and explain
whether the issue is a false negative, false positive, parser failure, or action
runtime problem.

Do not publish a third party's workflow finding as a vulnerability unless you
have independently demonstrated impact and followed that project's disclosure
policy. Authority Map is a conservative static discovery tool, not an exploit
scanner or proof of complete mediation.

We aim to acknowledge reports within 48 hours and provide an initial assessment
within seven days.
